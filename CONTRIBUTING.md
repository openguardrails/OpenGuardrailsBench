# Contributing to OpenGuardrailsBench (OGB)

Submit a detector adapter, an auditable public run, a scoring fix, or a newly authored public case with policy, evidence, target, label and rationale. State the model commit, template, quantization, hardware and inference budgets. Third-party dataset imports need a source revision, license review, redistribution status and deterministic builder; do not paste unlicensed benchmark corpora into this repository.

Do not submit private test cases, private outputs, customer traffic, real credentials or personal information in a public issue or PR. Keep a safe and unsafe counterexample together. Add tests for scoring and adapter correctness. A case label must follow its stated policy and evidence rather than assumptions about unstated authorization.

The initial release is a synthetic pilot. Promotion to a ranked edition requires independent label adjudication, contamination review, fixed reference models and a published calibration policy. Changes to cases, adapters, mappings, weights or metric definitions require a new frozen edition or documented pilot correction with new hashes and reruns.
