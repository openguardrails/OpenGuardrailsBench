01 / MEASURE BOTH SIDES

Blocking everything scores zero.

The index uses chance-corrected balanced accuracy. Every unsafe test has a legitimate counterpart. Errors and missing outputs lose credit; coverage stays visible.

02 / KEEP THE TEST HONEST

Public recipe. Private evidence.

Open cases and predictions make runs reproducible. Held-out cases and their raw outputs stay private. Only aggregate private scores reach this page.

03 / REPRODUCE A RESULT

Bring your model.

Run python -m ogb against an HTTP endpoint or a pinned model checkpoint. Outputs include raw predictions, configuration, hashes, and scoring receipts.
